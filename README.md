# RickyMenu
RickyMenu (short for "Right-Clicky Menu") is a declarative, no-dependency, fully-accessible, Javascript/HTML context-menu library.

# Development Status
This project is currently in PRE-ALPHA. For more information, look at ROADMAP.md in the root directory for this repository, and look at the Github Project.
