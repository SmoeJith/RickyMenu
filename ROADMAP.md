# Road Map
## Current Stage: `PRE-ALPHA`

## About
This project aims to add context menus in a way that is dependency-free, accessible, and declarative; using only widely-implemented W3C web standards, such as the Web Components API.

## Development Stages
This project's development will be split into four stages: PRE-ALPHA, ALPHA, BETA, and RELEASE.

> ### PRE-ALPHA
> The most basic features will be added so that one can attempt to use the library in non-production environments.

> ### ALPHA
> Additional basic features will be added so that the library can be reasonably considered complete enough for production use, sans production stability.

> ### BETA
> Additional features which either significantly improve the developer experience or would be nice to have may be added, but the main focus will be on locating bugs and squashing them to ensure that the software is stably usable in a production environment.

> ### RELEASE
> Once the RELEASE stage is reached; maintenance, enhancement, and bug-fixing will occur indefinitely.
